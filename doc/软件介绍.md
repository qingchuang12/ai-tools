# AI-Tools（MCP Dock）软件介绍

> 一款面向 AI 编程客户端的桌面应用，统一管理 MCP Server 与 Agent Skills 的配置，让开发者告别手动编辑 JSON、跨客户端同步的繁琐。

---

## 一、这是什么

**AI-Tools（产品名 MCP Dock）** 是基于 Electron 的跨平台桌面工具，用于集中管理各类 AI 编程客户端（Cursor、VS Code、Claude Code、Gemini CLI、Codex CLI、Trae、JetBrains、CodeBuddy 等）的 MCP Server 与 Agent Skills 配置。

在 AI 编程工具爆发式增长的今天，每个客户端都有自己的配置文件格式与存放路径。手动维护这些配置既容易出错，又难以在多工具间保持一致。AI-Tools 将这些配置收拢到一个界面中，提供浏览、搜索、安装、调试、备份、同步与云端存储的一站式体验。

- **当前版本**：1.2.5
- **支持平台**：Windows / macOS / Linux
- **开源协议**：MIT（源码）/ 专有（安装包）
- **项目主页**：<https://github.com/OldJii/mcp-dock>
- **数据存储**：`~/.ai-tools/`（macOS / Linux）、`%USERPROFILE%\.ai-tools\`（Windows）

## 二、核心功能

### 1. MCP 商店

浏览与搜索 **8500+ 个 MCP Server**，支持多数据源切换：

- **Smithery**（内置源）：官方社区注册表，支持关键词搜索、分类筛选、服务端分页与真实总数展示，与官方 Web 行为一致。
- **npm Registry**（内置源）：从 npm 包生态中发现 MCP 服务器，支持按平台分类与下载量排序。
- **百炼 Bailian**（内置源）：阿里云 Model Studio 的 MCP 服务器源，内置 **251 条离线索引**，无需配置、无需联网即可浏览。
- **ModelScope 模型社区**（平台直连）：MCP 广场服务端分页浏览，可在设置中绑定 API Token 后使用。

商店列表采用「磁盘缓存 + SWR」策略：首屏秒开，冷启动不再等待网络；列表缓存 1 小时、详情缓存 24 小时，过期后后台静默刷新，也可一键「强制刷新」。

### 2. Skills 商店

发现 **4400+ 个 AI Skills**（Agent 技能），兼容 `~/.agents/skills/` 统一标准（[skills.sh](https://skills.sh/)），覆盖 Cursor、Claude Code、Gemini CLI、Codex CLI、Opencode 等客户端。支持以下数据源：

- **ClawHub**（内置源）：公开技能趋势榜单，匿名即可浏览。
- **ModelScope**：技能广场，服务端分页 + 分类筛选，列表展示真实封面图、浏览量、下载量。
- **SkillHub / SkillsMP**：社区技能聚合平台。
- **虾评 Coze**：直连公开分页接口，绑定 API Key 后可直接在应用内下载安装。

商店支持关键词搜索、分类筛选（分类标签语言随界面语言自动切换）、排序、来源筛选、分页与每页条数调节，安装状态徽章自动刷新。

### 3. 一键安装与多端部署

选中一个 MCP Server 或 Skill，即可自动写入对应客户端的配置文件，无需手动复制粘贴 JSON：

- **多客户端同时安装**：一次选择多个目标客户端（如 Cursor + VS Code + Claude Code）批量写入。
- **卸载 / 更新**：从任意客户端卸载，或单独更新某个客户端中的配置。
- **手动安装标记**：在「我的库」中编辑过的 Server 会被标记为手动安装，线上商店更新不会覆盖本地调整。
- **自定义客户端**：可在设置中添加任意客户端（指定 MCP 配置文件路径与 Skills 目录），纳入统一管理。

### 4. MCP Inspector

内置交互式调试器，通过 MCP JSON-RPC 协议直接调用 Server 暴露的能力：

- 支持 **stdio / streamable-http / sse** 三种传输方式，可自定义启动命令、参数、环境变量与请求头。
- 连接后浏览 **Tools（工具）、Resources（资源）、Prompts（提示词）** 三类能力清单。
- 在图形界面中直接调用 Tool 并传参，实时查看返回结果（JSON 语法高亮）。
- 日志面板可拖拽调整高度，方便对照排查启动与调用过程中的输出。

### 5. 我的库（Library）

集中管理已安装的 MCP Server 与 Skills，提供两个标签页：

**MCP 标签页**
- 查看已安装 Server 及其所在客户端；编辑配置（命令、参数、环境变量等）。
- 单个或**批量多选**同步到多个客户端；卸载管理。

**Skills 标签页**
- 查看已安装 Skill 的详情与归属客户端，安装 / 卸载 / 更新（单个或一键全部更新）。
- **在线编辑**：直接编辑 SKILL.md 的 frontmatter 与正文，管理附属文件（新增 / 删除 / 重命名）。
- **导入**：从本地 `.zip` / `.skill` 文件或**已解压的 Skill 文件夹**导入；粘贴 GitHub 仓库链接自动解析并安装；也支持拖拽导入。
- **导出**：将多个 Skill 打包导出为 zip，便于分发与备份。
- **云端冲突处理**：同步到云端前自动检测冲突，可选择覆盖或跳过。

### 6. 配置管理与多端同步

统一管理所有客户端的 MCP 与 Skills 配置：

- 支持 **20 个内置客户端 + 云端存储**（MCP），**15 个 Skills 客户端**（见下节）。
- 自动检测各客户端的安装状态与配置路径；对格式差异（如 VS Code 使用 `servers` 键而非 `mcpServers`）做了适配，无需关心底层差异。
- 同一份配置一键同步到多个客户端，保证工具链行为一致；共享同一物理目录的客户端（如 TRAE CN 与 TRAE SOLO CN）会自动去重，避免重复写入。

### 7. 云端同步与一致性

将 MCP 与 Skills 配置推送到**自己的云端**，实现备份与跨设备同步，换机或重装后一键恢复：

- **两种传输方式**：Git（支持 SSH 私钥 / HTTPS Token / 匿名）与 SFTP（密码 / 私钥认证）。
- **后台同步任务队列**：启动自动拉取、手动推送均进入任务面板，实时展示进度，失败可一键重试。
- **一致性检测**：主动对比本地与云端的差异，逐条查看本地端 / 云端内容，确认后按需同步，避免误覆盖。
- **凭据安全**：云端仓库地址、令牌等凭据不落盘明文，仅以加密引用（SecretStore）存储。

### 8. 历史记录与回滚

每次修改配置（安装、卸载、更新、同步、编辑）自动备份：

- 备份列表展示时间、大小、涉及客户端与 Server / Skill 数量。
- **Diff 对比**：查看任意历史版本与当前版本的差异（新增 / 移除 / 修改，用颜色区分）。
- 一键恢复到任意历史版本；支持清空全部历史。

### 9. 平台源管理

在「设置」中管理商店数据源连接：

- **MCP 源**：内置 Smithery、npm、百炼；可新建 ModelScope 等平台直连连接。
- **Skill 源**：管理 ModelScope、SkillHub、SkillsMP、ClawHub、虾评 Coze 等连接（Base URL + API Token）。
- 每个连接支持**测试连接**（按平台探测真实 API 端点，避免误判）、启停、设为默认、删除，并可将连接配置导出。
- **API 令牌中心**：集中创建 / 导入 / 撤销 / 恢复 API 令牌，按作用域（skills:read、skills:download、models:read、models:download、admin）与到期时间精细管理，可随时在界面中查看或清除。

### 10. 运行时环境检测

自动检测本机 **Node.js、Python、Git** 的安装状态、版本与路径，为 MCP Server（`npx` / `uvx` 启动）与 Skill 安装提供环境参考，帮助快速定位「装了却跑不起来」的环境问题。

### 11. 主题与多语言

- **主题**：浅色 / 暗色 / 自动（跟随系统明暗切换，含 macOS 与 Windows 原生窗口适配）。
- **语言**：简体中文与英文，语言包按需懒加载，切换即时生效。

### 12. 安全与隐私

- 缓存与本地数据使用 **AES-256-GCM** 加密存储，密钥基于机器特征派生，无需弹窗。
- 所有外部链接仅允许 http / https 在系统浏览器打开，杜绝 file:// 等协议带出。
- 应用内置**安全 DNS（DoH）**，规避 DNS 污染；单实例锁防止重复启动。
- 主进程 / 预加载 / 渲染进程三层隔离，渲染层仅能通过白名单 IPC 通道访问能力。

## 三、支持的客户端

AI-Tools 当前支持 **21 个 MCP 客户端**（含云端存储）与 **15 个 Skills 客户端**（含云端存储）：

**MCP 客户端（21 个）**
Cursor、VS Code、Claude Code、Gemini CLI、Codex CLI、Windsurf、Zed、TRAE、TRAE CN、TRAE SOLO CN（TraeWork）、TRAE 插件（MarsCode）、Kiro、Opencode、JetBrains（IntelliJ / WebStorm / PyCharm 等）、Antigravity、OpenClaw、CodeBuddy、WorkBuddy、Qoder、ZCode、云端存储（Cloud）。

**Skills 客户端（15 个）**
Cursor、Claude Code、Gemini CLI、Codex CLI、Opencode、Agent Skills（`.agents`）、CodeBuddy、WorkBuddy、Qoder、ZCode、MarsCode、TRAE、TRAE CN、TRAE SOLO CN（TraeWork）、云端存储（Cloud）。

> 客户端安装状态会被自动检测，界面仅展示本机已安装的客户端，也可在设置中自定义配置路径或添加自定义客户端。

## 五、适合谁用

- **日常使用多个 AI 编程工具的开发者**：希望 MCP 配置在各工具间保持一致。
- **MCP Server / Skill 作者**：需要频繁调试、验证自己的配置在各客户端是否生效。
- **团队 / 企业**：通过云端同步统一分发团队共用的 MCP 与 Skill 配置。

## 六、快速上手

1. 从 [Releases](https://github.com/OldJii/mcp-dock/releases) 下载对应平台安装包并安装。
2. 打开应用，左侧「MCP 商店」浏览或搜索需要的 Server，切换到「Skills」标签浏览技能。
3. 点击「安装」，选择目标客户端（如 Cursor、VS Code），可多选。
4. 到对应客户端中即可直接使用该 MCP / Skill 能力。
5. 配置有误时，可先用「Inspector」页联调；进入「历史」页一键回滚。
6. 多设备用户可在「设置 → 云同步」中配置 Git 或 SFTP 云端，实现跨设备同步。

所有配置与数据均存储在本地（`~/.ai-tools/`），首次加载商店列表需联网，已安装配置离线可用。

## 七、技术亮点

- **三层进程架构**：主进程（配置读写 / IPC / 云同步）、预加载（安全桥接）、渲染进程（React 界面），职责清晰。
- **20+ 客户端适配层**：`config-manager` 统一抽象各客户端的路径、格式（如 VS Code 使用 `servers` 键而非 `mcpServers`）与安装检测。
- **统一平台适配器**：`platforms/registry` 注册表机制，新增数据源只需注册一个 adapter，无需改动界面层。
- **云端同步服务**：Git / SFTP 双通道，`cloud-sync-service` + 后台任务队列 + 一致性检测。
- **安全缓存**：AES-256-GCM 加密缓存 + SWR 策略，兼顾速度与安全。
- **多进程清理**：Inspector 子进程随应用退出自动回收，避免残留。

**技术栈**：Electron 43 · React 18 · TypeScript 5.3 · Tailwind CSS 3.4 · Zustand 4 · TanStack Query 5 · Vite 7 · electron-builder 24 · Vitest 4 · MCP SDK。
